## What I did, step by step

1. Chose practical testing, delivery and support problems that can be demonstrated with inspectable work.
2. Built applications and isolated labs, using fictional data where real records would be inappropriate.
3. Checked behaviour with tests and direct service observations, retaining failed experiments and scope limits.
4. Published project documentation, demos and evidence, then organised this index around relevant jobs.

## Key decisions

- **Group projects by the work they prove:** testing, analysis, delivery, support, security, automation and data each have an entry point below.
- **Link public, reviewable evidence:** hosted replays and fictional-data previews are labelled. Private research and video projects are omitted; each listed project explains its own limits.
